# 🎰 Meme Casino

Мемное мини-казино в виде расширения для браузера Firefox. 
Игра на вымышленные очки с системой банка, множителей, бомб и динамическим шансом выпадения.

## 🚀 Как установить
1. Скачай проект.
2. Открой в Firefox `about:debugging#/runtime/this-firefox`.
3. Нажми «Загрузить временное дополнение» и выбери `manifest.json`.

## 📦 Стек
- Чистый HTML
- CSS
- Vanilla JavaScript
